Personal architecture growth roadmap for Valentinas.

---

## Phase 1 – Core Theory
**Goal:** Build conceptual foundation.
- Read: *Fundamentals of Software Architecture* (Richards & Ford).
- Study quality attributes, coupling/cohesion, trade-offs.
- Summarize each attribute → measurable goal.
- Apply: refine ARC42 §1–§4.

---

## Phase 2 – Modeling & Documentation
**Goal:** Communicate effectively.
- Learn C4 Model (Simon Brown).
- Master ARC42 structure.
- Practice writing ADRs.
- Apply to real systems (Hub, Management, Forecast APIs).

---

## Phase 3 – Metrics & Evaluation
**Goal:** Architecture as measurable system.
- Read: *Software Architecture Metrics* (Ciceri).
- Define local metrics (coupling, instability, maintainability index).
- Implement tracking (SonarQube, NDepend, GitHub checks).
- Run quarterly ATAM-lite workshop.

---

## Phase 4 – Distributed & Resilient Systems
**Goal:** Event-driven, async, failure-tolerant design.
- Study *Building Evolutionary Architectures* (Ford, Parsons, Kua).
- Learn Sagas, Outbox, CQRS.
- Prototype async workflows with RabbitMQ or Kafka.

---

## Phase 5 – Leadership & Facilitation
**Goal:** Enable others.
- Read: *Facilitating Software Architecture* (Harmel-Law).
- Mentor teams on ADRs and principles.
- Automate rules via templates, CI/CD governance.

---

## Continuous Practice
- Weekly: watch 1 architecture talk (Mark Richards, Neal Ford, ThoughtWorks Tech Radar).
- Monthly: update Tech Radar + review metrics.
- Quarterly: refactor one pattern (extract module, decouple dependency).
